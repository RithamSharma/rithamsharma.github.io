The idea

Make processor execution visible without treating observability as an afterthought.

The core

VisuCore implements a five-stage RV32I pipeline with forwarding, load-use interlocks, branch flushes, trap handling and a 256-byte direct-mapped write-back data cache.

The trace path

An event packetizer moves execution state through a FIFO and 115,200-baud UART link. The Python dashboard above can connect to hardware or replay deterministic recordings.
